# Evaluacion Blazor Biblioteca

Proyecto de evaluación desarrollado utilizando:

- Blazor Web App .NET 8
- Entity Framework Core
- SQL Server
- HttpClient
- EditForm
- WebAssembly

## Funcionalidades

- Agregar libros
- Actualizar libros
- Eliminar libros
- Listar libros
- Validación de formularios
- Métodos asíncronos
- Directiva @key
- Ciclo de vida OnInitializedAsync
